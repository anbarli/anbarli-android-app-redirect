Shows an Open in App banner to Android visitors and redirects to Google Play when the app is not installed.

Android ziyaretçilere Uygulamada Aç bildirimi gösterir; uygulama yüklü değilse Google Play'e yönlendirir.

== Description ==

Anbarlı Android App Redirect is a lightweight, theme-independent plugin for connecting a WordPress website with its Android application.

The banner can be shown to all Android visitors or only to logged-in users. It stays hidden in PWA/standalone mode and can remember when a visitor dismisses it.

Anbarlı Android App Redirect, WordPress sitenizi Android uygulamanıza bağlayan hafif ve temadan bağımsız bir eklentidir.

Bildirim tüm Android ziyaretçilere veya yalnızca giriş yapmış kullanıcılara gösterilebilir. PWA/standalone modunda gizlenir ve kullanıcının kapatma tercihini belirlenen süre boyunca hatırlayabilir.

Source code / Kaynak kod: https://github.com/anbarli/anbarli-android-app-redirect

== Installation ==

1. Upload and activate the plugin ZIP.
2. Go to Settings > Android App Redirect.
3. Enter the Android package name and Google Play URL.
4. Configure visibility and banner text, then save.

Türkçe:

1. Eklenti ZIP dosyasını yükleyip etkinleştirin.
2. Ayarlar > Android App Redirect sayfasını açın.
3. Android paket adını ve Google Play adresini girin.
4. Görünürlük ve bildirim metinlerini ayarlayıp kaydedin.

== Frequently Asked Questions ==

= What happens if the app is not installed? / Uygulama yüklü değilse ne olur? =

The configured Google Play page opens. / Ayarlanan Google Play sayfası açılır.

= Does it work with PWA plugins? / PWA eklentileriyle çalışır mı? =

Yes. The banner is not displayed when the site is opened in standalone/PWA mode.

Evet. Site standalone/PWA modunda açıldığında bildirim gösterilmez.

= Does it automatically log the user into the Android app? =

No. WordPress and Android application authentication must be integrated separately.

= Android uygulamasında kullanıcıyı otomatik olarak oturum açtırır mı? =

Hayır. WordPress ve Android uygulama kimlik doğrulaması ayrıca entegre edilmelidir.
