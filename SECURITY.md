# Security Policy

## Supported Versions

The latest release is supported with security fixes.

## Reporting a Vulnerability

Please do not open a public issue for a suspected security vulnerability.

Report it privately through GitHub Security Advisories for this repository, or contact the maintainer through the profile listed on the repository.

Include:

- A clear description of the issue
- Steps to reproduce
- Affected plugin version
- WordPress and PHP versions
- Any relevant browser or Android details

The maintainer will review the report and coordinate a fix before public disclosure when needed.
