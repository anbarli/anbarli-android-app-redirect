# Contributing

Thanks for helping improve Anbarli Android App Redirect.

## Local Checks

This plugin has no build step. Before opening a pull request, run:

```bash
php -l anbarli-android-app-redirect.php
php -l uninstall.php
```

## Pull Requests

- Keep changes focused on one feature or fix.
- Include a short description of the WordPress and Android behavior you tested.
- Update `README.md` or `readme.txt` when changing setup, configuration, or user-facing behavior.
- Avoid unrelated formatting churn.

## Good First Contributions

- Add screenshots for the settings page and Android banner.
- Improve troubleshooting notes for specific Android browsers.
- Add translation files.
- Add WordPress coding standards checks.
- Add filters for advanced banner visibility rules.

## Reporting Issues

Please include:

- WordPress version
- PHP version
- Android browser and version
- Android package name format, without private credentials
- Whether Android App Links are verified
- Steps to reproduce the issue
